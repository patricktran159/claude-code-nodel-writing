# Image-Generation Prompts: *Close Contact*

> Two sections. **Section 1** holds one fixed visual description per character. **Section 2** holds one illustration prompt per chapter, meant to appear at the head of the chapter.
>
> **Rules used:** (1) Every character description in Section 2 is copied **word for word** from Section 1. (2) Each prompt is **self-contained**: it carries its own style, scene, character descriptions, format and exclusions, so it can be pasted into an image generator on its own. (3) Scene-specific clothing is added *after* the fixed description and never changes the person.
>
> **Consistency tips:** use the same generator and model for all five images; where the tool allows, first generate a plain character sheet for Nell and Theo from Section 1, then use it as a reference image; keep the same seed or style reference across prompts; if a face drifts, re-state the full description rather than shortening it.

---

## Section 1. Character descriptions

Each description is written to be reused unchanged. It fixes age, build, skin, eyes, brows, hair and any signature item (Nell's steel watch, Theo's flour-dusted forearms and burn scar, Elly's pencil behind the ear). Clothing varies by scene and is set in Section 2.
